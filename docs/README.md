# Project Documentation

This directory contains project audits, architecture notes, dependency reviews, and implementation records.

## Start here

- `IMPLEMENTATION_STATUS.md` — current verified status and known limitations

- `QUICK_REFERENCE.md` — overview and navigation
- `ARCHITECTURE_DIAGRAM.md` — application structure and data flow
- `RESOURCE_AUDIT.md` — asset and resource review
- `FILE_DEPENDENCY_MAP.md` — file relationships
- `AUDIT_REPORT.md` — detailed findings

Historical implementation notes and cleanup records are kept here to avoid cluttering the application root.
